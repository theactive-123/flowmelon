Most ranking drops after a migration have nothing to do with the new platform. They come from missing redirects, rewritten headings, lost metadata and a launch that nobody watched. Webflow is excellent for SEO — clean markup, fast global hosting, editable meta on every page — but only if the move itself is handled carefully.

This is the six-step checklist we use for agency partners moving sites from WordPress, Wix, Squarespace and HubSpot. It works for a 20-page brochure site and for a 2,000-item blog; the bigger the site, the more each step matters.

1. Crawl and inventory everything

Before anyone opens Figma, take a full snapshot of the live site. You can’t protect what you haven’t measured.

  • Crawl every URL with Screaming Frog or Sitebulb. Export status codes, titles, meta descriptions, H1s, canonicals and word count.
  • Pull 12 months of data from Google Search Console and Analytics: clicks, impressions and landing-page sessions per URL.
  • Export backlinks from Ahrefs or Semrush so you know which pages other sites point to.
  • Note structured data — FAQ, product, article and breadcrumb schema all need to survive the move.

Merge it into one sheet. Sort by clicks and backlinks; the top 20% of URLs usually carry 80% of the organic value, and those pages get the most care.

2. Map every URL to its new home

Build the redirect map while the sitemap is still being designed, not the week before launch. Every legacy URL gets exactly one destination.

  1. Keep the same slug wherever you can. The safest redirect is the one you don’t need.
  2. Merged or renamed pages get a 301 to the closest relevant page — never a blanket redirect to the homepage.
  3. Retired content with backlinks gets redirected to the most related surviving page.
  4. Thin pages with no traffic and no links can return a 410 and leave quietly.

/category/webflow            →  /blog?topic=webflow

/contact-us                  →  /contact

3. Rebuild with the same intent

A redesign is the perfect moment to improve a site — and the most common moment to break its SEO. Redesign the look freely, but treat the ranking signals as part of the brief:

  • Keep the H1 and primary heading structure of pages that rank. Tighten copy, don’t delete the topic.
  • Move titles and meta descriptions over exactly, then improve them deliberately afterwards.
  • Recreate internal links. Navigation changes often orphan pages that used to be two clicks deep.
  • Bind CMS fields to SEO settings so every new blog post gets a title, description and Open Graph image automatically.
  • Add alt text to every meaningful image and rebuild structured data with a custom embed or CMS-driven JSON-LD.
“Rankings rarely drop because of Webflow. They drop because of missing redirects and forgotten metadata.”— Every migration post-mortem we’ve ever read

4. Make it faster than before

Speed is a ranking factor and a conversion factor. Webflow gives you a fast CDN out of the box; the rest is discipline:

  • Serve images as WebP or AVIF with responsive sizes, and lazy-load everything below the fold.
  • Keep custom code light. Load animation libraries once, site-wide, instead of per page.
  • Preload the two fonts you actually use and drop the weights you don’t.
  • Check Largest Contentful Paint on mobile — the hero image is usually the culprit.

5. Test on staging, then switch DNS

Run the whole redirect map against the staging domain before launch. A simple script that requests each old path and checks for a single 301 hop to the right destination catches 95% of problems.

  1. Crawl staging and compare titles, H1s and canonicals against your original inventory.
  2. Test every form, integration and analytics event end to end.
  3. Lower the DNS TTL to 300 seconds a day early so the cutover is quick.
  4. Publish, switch DNS, then submit the new sitemap in Search Console the same hour.

6. Monitor for 30 days

Launch day is the start of the migration, not the end. For the next month:

  • Check Search Console coverage daily for the first week, then weekly.
  • Fix any 404 the same day it appears — it’s almost always a missed redirect.
  • Compare rankings for your top 50 keywords weekly. Small wobbles in week one are normal; steady drops are not.
